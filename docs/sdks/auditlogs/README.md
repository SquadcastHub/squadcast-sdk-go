# AuditLogs

* [AuditLogsGetAuditLogsExportHistoryByID](#auditlogsgetauditlogsexporthistorybyid) - Get details of Audit Logs export history by ID
* [AuditLogsGetAuditLogByID](#auditlogsgetauditlogbyid) - Get audit log by ID
